# Installer Pro

**EN** — A silent offline installer for Windows 10 & 11. It keeps all your installer files in one library and runs them in order with silent install, so you don't have to sit at the machine. No internet needed while installing.

**AR** — أداة تثبيت صامت لويندوز 10 و11، بتجمع ملفات التثبيت في مكتبة واحدة وتشغلها بالترتيب من غير ما تقعد قدام الجهاز، وبدون إنترنت أثناء التثبيت.

🌐 **Website / الموقع:** https://saqr365.github.io/installer-pro/

## Features / المميزات
- Silent install, no prompts / تثبيت صامت بدون نوافذ
- Categories, priorities and dependencies / تصنيفات وأولويات واعتماديات
- Multiple steps per program: installer, script, folder, registry, shortcut / خطوات متعددة لكل برنامج
- Tags and search / وسوم وبحث
- Saved lists, command-line run / قوائم محفوظة وتشغيل من سطر الأوامر
- Update detection and uninstall / اكتشاف التحديثات وإزالة البرامج
- Automatic backup of your library / نسخ احتياطي تلقائي للمكتبة
- Arabic + English, light + dark / عربي وإنجليزي، فاتح وداكن
