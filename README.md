# Installer Pro — landing page / موقع التعريف

Static site (HTML + CSS + JS), no build tools. Arabic (RTL) + English (LTR), light + dark theme.
موقع ثابت بدون أدوات بناء، عربي وإنجليزي، وضع فاتح وداكن.

## Download link / رابط التحميل
Edit `DOWNLOAD_URL_APP` (the app) and `DOWNLOAD_URL_PACK` (the essential apps pack) at the top of `assets/js/main.js`.

## Text / النصوص
All copy lives in the `T` object in `assets/js/main.js` (`ar` and `en`).

## Deploy / النشر
GitHub Pages: push this folder to the repo root, then Settings > Pages > Deploy from a branch > `main` / root. Paths are relative.
